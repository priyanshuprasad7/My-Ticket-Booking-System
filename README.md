# Bihar Railway Ticket Booking System 🚆

A pure Java console-based railway ticket booking system designed around a fictional Bihar railway dataset.

This project is being developed step-by-step to practice real-world Java programming, Object-Oriented Programming, Collections, validation, and project structure.

> **Note:** This project uses fictional/sample railway data. It is not connected to Indian Railways or any live railway system.

---

## 📌 Version 1

Version 1 focuses on the core ticket-booking workflow.

### Features

- 🚉 Station management
- 🚆 Train and route management
- 🛤️ Multiple train stoppages
- 🔍 Search trains between source and destination
- ✅ Source and destination validation
- 🚆 Train selection
- 💺 Seat availability and seat assignment
- 👤 Passenger details
- 🎫 Booking ID generation
- 📋 Booking creation
- 💾 Store bookings in memory
- 🧾 Generate and display an e-ticket
